# 🐍 My Python Projects

Hi! Welcome to my Python repository. I am learning programming and using this space to practice building simple tools and games.

---

## 📌 Projects Included

* 📐 **Area Calculator (`Calculator.py`):** Calculates the area of different shapes (like squares, rectangles, triangles, and circles).
* ⏱️ **Countdown Timer (`Countdown_Timer.py`):** Counts down the seconds for a timer.
* 🎮 **Rock, Paper, Scissors (`Rock_paper_scissors.py`):** A fun game you can play against the computer.
* 🌡️ **Temperature Converter (`Temperature_Conversion.py`):** Converts temperatures between Celsius and Fahrenheit.
* ⚖️ **Weight Converter (`Weight_Convertor.py`):** Converts weight measurements between kilograms and pounds.
